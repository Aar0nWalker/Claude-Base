# автопилот — автономный цикл

Запускать только по явному `автопилот` или `/автопилот`.

1. Прочитать `.agents/skills/base/autopilot/SKILL.md` полностью.
2. Следовать его ограничениям по деньгам, production, маленьким срезам и остановке.
3. Использовать штатную автоматику текущего агента, если требуется повторный запуск; не придумывать
   фоновый процесс без согласия пользователя.
4. Если пользователь пишет `stop autopilot`, остановить созданное расписание и подтвердить.
