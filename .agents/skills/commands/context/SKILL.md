# контекст — быстрый вход в проект

Запускать, когда пользователь пишет `контекст` или `/контекст`.

1. Прочитать `SESSION_HANDOFF.md`, `ARCH.md`, `STACK.md`; `AGENTS.md` Codex уже загрузил.
2. Проверить `git status` и активные рабочие деревья через `git worktree list`.
3. Скилы не грузить до появления конкретной задачи; весь репозиторий не сканировать.
4. Ответить ровно: `Ознакомился, готов работать`.

Если дерево грязное или есть незавершённая соседняя ветка, добавить одну строку предупреждения.
