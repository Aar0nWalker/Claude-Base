# выкати — release

Запускать, когда пользователь пишет `выкати` или `/выкати`.

Полностью прочитать `.claude/commands/выкати.md` и выполнить общую процедуру. Файл является
каноническим release-контрактом для обоих агентов; названия интерфейсов конкретного агента не
меняют последовательность: pre-check → полный gate → release → внешняя health/log проверка →
commit явных путей → push. Красный gate, грязное чужое дерево или отсутствующий release target
останавливают выпуск; обход агент не выбирает сам.
