# контекст — быстрый вход в проект

Запускать, когда пользователь пишет `контекст` или `/контекст` (обычно первое сообщение нового чата).

## Шаги

1. Прочитать по порядку:
   - `AGENTS.md` (правила, параллельная работа, оркестрация) — подгружается автоматически через
     `@../AGENTS.md`, перечитывать не нужно.
   - `SESSION_HANDOFF.md` — текущее прод-состояние и незавершённое.
   - `ARCH.md` — архитектура, модели, request flow, карта модулей.
   - `STACK.md` — версии и технологии.
2. Проверить актуальность снимка: `rtk git status` и `.agents/wip.md` (чужие активные зоны).
3. Скилы **не** грузить — только тот, что понадобится под конкретную задачу.
4. Репозиторий не сканировать.

## Ответ

Вывести ровно одну строку и ничего больше:

```
Ознакомился, готов работать
```

Исключение: если `git status` грязный или в `.agents/wip.md` висит чужая активная строка —
добавить одну строку предупреждения после неё.
