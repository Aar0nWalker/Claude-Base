# Oridium — актуализация агентской базы

## Цель

Один нейтральный набор правил работает в Claude Code и Codex: каждый агент автоматически находит
инструкции, скилы и четыре базовые команды, а README объясняет человеку, что где лежит.

## Изменения

1. Зеркально опубликовать базовые скилы для Codex в `.agents/skills/`, сохранив Claude-источник в
   `.claude/skills/base/`.
2. Добавить Codex-обёртки для команд `контекст`, `выкати`, `запакуй`, `автопилот`.
3. Обновить README, AGENTS и authoring-документ: общая карта, выбор агента, правила синхронизации.
4. Добавить короткое техническое описание обнаружения правил, скилов и команд обоими агентами.

## Проверка

- у каждой Claude-команды есть Codex `SKILL.md` с тем же назначением;
- каталоги базовых скилов совпадают, включая tools;
- все относительные ссылки существуют;
- в репозитории нет секретов и прикладных правил Crona;
- `scripts/ci/test-lifecycle-check.sh` и `git diff --check` зелёные.
